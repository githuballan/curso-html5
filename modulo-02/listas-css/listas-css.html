Dividindo Listas em Colunas com CSS

Você sabia que pode dividir uma lista em várias colunas usando CSS? Isso é especialmente útil quando você tem uma lista longa e deseja economizar espaço na página. Para fazer isso, basta utilizar a propriedade "columns".

Veja um exemplo de código:

<ol style="columns: 2;" type="I">
    <li>Acordar</li>
    <li>Preparar o Café</li>
    <li>Tomar Banho</li>
    <li>Tomar o café</li>
    <li>Etc..</li>
</ol>

Veja como fica visualmente:

  1. Acordar
  2. Preparar o Café
  3. Tomar Banho
  4. Tomar o café
  5. Etc..

Tipos de list-style-type

As listas são uma parte essencial do design da web, mas nem sempre são visualmente atraentes. Felizmente, você pode estilizar suas listas com CSS para torná-las mais atraentes e personalizadas.

Abaixo estão alguns exemplos de diferentes tipos de "list-style-type" que você pode usar em suas listas:

  • Disc
    • style="list-style-type: disc;"
  • Circle
    • style="list-style-type: circle;"
  • Square
    • style="list-style-type: square;"
  • Decimal
    • style="list-style-type: decimal;"
  • Decimal Leading Zero
    • style="list-style-type: decimal-leading-zero;"
  • Lower Roman
    • style="list-style-type: lower-roman;"
  • Upper Roman
    • style="list-style-type: upper-roman;"
  • Lower Alpha
    • style="list-style-type: lower-alpha;"
  • Upper Alpha
    • style="list-style-type: upper-alpha;"
  • None
    • style="list-style-type: none;"

Exemplo de código:

<ol style="list-style-type: lower-roman;">
    <li>Acordar</li>
    <li>Preparar o Café</li>
    <li>Tomar Banho</li>
    <li>Tomar o café</li>
    <li>Etc..</li>
</ol>

Veja o resultado:

  1. Acordar
  2. Preparar o Café
  3. Tomar Banho
  4. Tomar o café
  5. Etc..

Usando Marcadores Personalizados

Além dos marcadores padrão, você pode usar outros símbolos com CSS para deixar suas listas mais interessantes e personalizadas. Por exemplo, você pode usar um símbolo de checkmark (✔) para indicar tarefas concluídas.

Exemplo de código:

Abaixo estão alguns exemplos de diferentes tipos de marcadores personalizados que você pode usar em suas listas:

  • Checkmark
    • style="list-style-type: '\2713';"
  • THREE-D TOP-LIGHTED RIGHTWARDS ARROWHEAD
    • style="list-style-type: '\27A2';"
  • Heavy Checkmark
    • style="list-style-type: '\2714';"
  • Heavy Multiplication
    • style="list-style-type: '\2716';"
  • Circled White Star
    • style="list-style-type: '\272A';"
  • Shadowed White Star
    • style="list-style-type: '\2730';"

Para consultar os códigos de marcadores personalizados, você pode visitar o site W3Schools - UTF-8 Dingbats. Lá você encontrará uma lista completa de caracteres que podem ser usados como marcadores em suas listas.

                <li>Preparar o Café</li>
                <li>Tomar Banho</li>
                <li>Tomar o café</li>
                <li>Etc..</li>
            </ul>

  • Acordar

Usando Imagens como Marcadores

Você pode usar imagens personalizadas como marcadores em suas listas com a propriedade "list-style-image". Isso permite que você adicione um toque único ao design da sua página.

Exemplo de código:

        <ul style="list-style-image: url('...img.ico')">
            <li>Acordar</li>
            <li>Preparar o Café</li>
            <li>Tomar Banho</li>
            <li>Tomar o café</li>
            <li>Etc..</li>
        </ul>

Veja como fica:

  • Acordar
  • Preparar o Café
  • Tomar Banho
  • Tomar o café
  • Etc..

Ao usar imagens como marcadores, certifique-se de que elas sejam leves, pequenas e sem muitos detalhes para garantir uma boa performance e clareza visual.

Removendo Marcadores

Quer remover os marcadores da lista? Isso pode ser útil quando você deseja que a lista pareça mais limpa ou quando os marcadores não se encaixam no design da sua página. É simples, basta usar "none" na propriedade "list-style-type".

Exemplo de código:

<ol style="list-style-type: none">
    <li>Acordar</li>
    <li>Preparar o Café</li>
    <li>Tomar Banho</li>
    <li>Tomar o café</li>
    <li>Etc..</li>
</ol>

Veja como fica:

  1. Acordar
  2. Preparar o Café
  3. Tomar Banho
  4. Tomar o café
  5. Etc..

Aumentando a Distância do Marcador

Para aumentar a distância entre o marcador e o texto, você pode usar um estilo externo com "list-style-type". Seguido de uma belíssima "gambiarra". Mas isso pode ajudar a melhorar a legibilidade da lista.

Exemplo de código:

<ol style="list-style-type: '\2714\0020\0020\0020\0020\0020\0020\0020\0020\0020\0020">
    <li>Acordar</li>
    <li>Preparar o Café</li>
    <li>Tomar Banho</li>
    <li>Tomar o café</li>
    <li>Etc..</li>
</ol>

Veja como fica:

  1. Acordar
  2. Preparar o Café
  3. Tomar Banho
  4. Tomar o café
  5. Etc..

Obs.: 0020 é um código hexadecimal para espaço, assim como 00A0.
